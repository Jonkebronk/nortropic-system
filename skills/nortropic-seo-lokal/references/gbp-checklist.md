# Google Företagsprofil — Per-Client Checklist Template

**Executed by a HUMAN in business.google.com** (the GBP API cannot create listings and API access is impractical for one-off sites). This template is filled per client by seo-optimizer and included in the handover doc. Time: ~30–45 min + verification wait.

> **Endast skarpa klienter.** Kör aldrig denna checklista för en TESTKLIENT: inga anspråk på listningar, inga citations, inga omdömesförfrågningar. Fiktiva företag får ingen Google-närvaro.

## A. Skapa/gör anspråk
- [ ] Search the business on Google Maps first — claim the existing listing if one exists (duplicates kill local rank)
- [ ] Exact name = `content/business.ts` name (no keyword stuffing — "Rörjour Stockholm AB", NOT "Rörjour Stockholm AB | Bästa rörmokaren")
- [ ] Verify (postcard/phone/video — whatever Google offers). Start EARLY: postcard = 1–2 veckor

## B. Kategori (biggest ranking lever)
- [ ] **Primary category** = the exact trade in Swedish: Rörmokare / Elektriker / Städfirma / VVS-firma / Låssmed / Målare / Byggfirma...
- [ ] Secondary: 2–4 genuinely applicable ("Jourrörmokare", "Värmepumpsinstallatör") — never aspirational

## C. NAP + kontakt
- [ ] Address exactly as on the site footer (or **service-area business** with hidden address if working from home — then set service areas by kommun instead)
- [ ] Phone = the site's main number (call tracking numbers: NO — NAP consistency wins)
- [ ] Website → homepage; Appointment link → `/kontakt#offert`

## D. Öppettider
- [ ] Regular hours = site's öppettider · Jour: set 24 h only if truly staffed
- [ ] Add helgdagar (Google prompts before röda dagar — answer them; "Kan vara stängt" hurts)

## E. Innehåll
- [ ] Beskrivning (750 tecken): what + where + proof, first 250 chars carry the message, no keyword stuffing
- [ ] **Tjänster**: add every service from `/tjanster/*` with fr.-priser where the site shows them
- [ ] **Foton**: logo, omslagsbild, team (3+), bilar med dekal, jobb/before-after (10+ total). Real photos — GBP with stock photos converts ~0
- [ ] Attribut: relevant ones only (t.ex. "Kvinnligt ledd", betalningssätt)

## F. Omdömen (ongoing — handover to client)
- [ ] Generate the direct review link (Ask for reviews) → give to client for faktura/SMS/QR
- [ ] Respond to every review in Swedish ≤7 days (owner or Nortropic per agreement)
- [ ] Never buy/incentivize/gate reviews

## G. Efter lansering
- [ ] UTM-tag the website link if GA4 is used (`?utm_source=google&utm_medium=organic&utm_campaign=gbp`)
- [ ] Post 1 Google-inlägg/månad minimum (before/after, säsong: "Dags för vinterservice av värmepumpen")
- [ ] Check Insights monthly: calls, direction requests, website clicks — report in client follow-up

## Red flags to avoid
Keyword-stuffed name (suspension risk) · virtual office addresses · multiple listings same business · category flip-flopping · review bursts (10 in one day looks bought)
